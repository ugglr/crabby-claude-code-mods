# Claude Code mods

Every public Claude Code mod we could find, 235 of them, with a picture where the author published one.

Mods are plugins that run code inside Claude Code: they draw panes, bands and status lines, and hook into prompts and tool calls. They need Claude Code 2.1.287 or later. Mods are not sandboxed, so read the source before you install one.

## Usage and limits

- [bash-diet](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/bash-diet) - Shrinks each Bash result with per-command filters before the model reads it, keeping the full output available.
- [cache-meter](https://github.com/DarioFontanel/claude-code-mods/tree/main/cache-meter) - A bar above the prompt that drains as the hour of prompt cache runs out.
- [cache-timer](https://github.com/arasovic/claude-code-mods/tree/main/cache-timer) - Counts down to when the prompt cache expires so you can send before it goes cold.
- [cache-timer](https://github.com/EricJamie/claude-code-mods/tree/main/plugins/cache-timer) - A countdown to prompt cache expiry, shown in the prompt footer before the model name.
- [context-band](https://github.com/EricJamie/claude-code-mods/tree/main/plugins/context-band) - A band above the prompt with rate limits, tokens, speed, cache, cost and context fill.
- [context-level](https://github.com/tobihagemann/turbo/tree/main/claude/skills/context-level) - Gives Claude a tool that reads how much of the context window remains.
- [context-tokens](https://github.com/0xBADC0FFEE/claude-code-mods/tree/main/context-tokens) - Shows context tokens in use beside the desktop app's prompt footer, colored green, yellow or red.
- [cost-git](https://github.com/juulsverne/claude-code-mods/tree/main/cost-git) - A band above the prompt with session cost, git branch and status, CI, and pull and push buttons.
- [effort-auto](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/effort-auto) - Has a small model rate each prompt's difficulty and runs that turn and its subagents at a matching effort.
- [gemini-compact](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/gemini-compact) - Hands context compaction to Gemini so the summary does not count against your Claude usage.
- [jev-model-router](https://github.com/davila7/claude-code-templates/tree/main/cli-tool/components/mods/productivity/jev-model-router) - Chooses the model and reasoning effort for each task using TypeSafe's Jev decision model.

## Add a mod

Add an entry to `mods.json`, run `python3 build.py` and open a pull request. A mod qualifies when its repository is public, its `hooks/hooks.json` lists `modules`, and its README says how to install it. Describe what it does in one plain sentence.
